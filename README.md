# MHGURecomp_FSR4_LightweightPatcher
Patches back in the FSR4 to the MHGURecomp

## Requirement:
• MHGURecomp by morerokk (Tested on 0.13.1)  
→ https://github.com/morerokk/MHGURecomp  
• amd_fidelityfx_loader_vk.dll and amd_fidelityfx_upscaler_vk.dll from the AMD SDK (Tested on v2.4)  
→ https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK
• FSR4-capable GPU (Tested on RX6600)

Installation:
1. Copy the content of the zip file to MHGURecomp folder.
2. Put the "amd_fidelityfx_loader_vk.dll" and "amd_fidelityfx_upscaler_vk.dll" in the MHGURecomp folder.
3. Run the MHGURecomp and enable the FSR from the settings. Close the game afterward.
4. Open the "mhgurecomp.ini" and set the "Upscaler" to "FSR4". Save the changes, obviously.
5. Run the game using the "Start-MHGURecomp-FSR4.bat".
